# AGENTS.md — 生活心理學小筆記

## 專案目的
本專案是一個以繁體中文撰寫的「生活心理學小筆記」靜態網站，提供心理學概念的簡短解釋、生活例子、搜尋收藏與小測驗。受眾是想快速複習的學生和對心理學感興趣的一般讀者。

**重要：** 目前是知識整理與互動練習網站，不是有 Gemini / RAG 功能的聊天機器人。不要在未實作前宣稱具備 AI 自動回答功能。

## 技術與執行方式
- 使用原生 HTML、CSS、JavaScript（不使用 React、後端、資料庫或需要編譯的工具）。
- 網頁必須在 GitHub Pages 的「Deploy from a branch / main / (root)」環境運作。
- 不需要 API Key，不儲存任何個人資料。收藏紀錄只存在使用者本機的 localStorage。
- 所有站內連結、CSS 與 JS 請使用 **相對路徑**（如 `./concepts.html`、`./assets/style.css`），不要使用 `/assets/...` 絕對路徑，以免 GitHub Pages 子路徑失效。

## 資料夾與檔案結構
- `index.html`：首頁，說明網站用途並推薦概念。
- `concepts.html`：概念總覽，可搜尋、依類別篩選及只看收藏。
- `article.html`：概念詳情頁，透過 `?id=概念id` 讀取資料。
- `quiz.html`：互動測驗頁，顯示題目與解析。
- `about.html`：網站目的、設計與限制。
- `assets/data.js`：**內容單一來源**。所有概念與測驗題都從此檔案讀取。
- `assets/app.js`：共用導覽、搜尋、收藏及測驗互動邏輯。
- `assets/style.css`：版面、色彩、響應式設計。
- `README.md`：使用方法、部署方式與專案說明。
- `AGENTS.md`：本檔，指導 AI 未來如何延伸本專案。

## 風格與語言
- 網站文字統一使用自然的臺灣繁體中文，語氣清楚、親切但不要過度口號化。
- 視覺風格：米白背景、深綠主要文字、珊瑚橘重點色；留白適中；像一本整理好的筆記，而非企業式管理儀表板。
- 桌機、平板、手機皆需可正常瀏覽；互動元件要有可見焦點、標籤與適當對比。
- 文字內容避免「你一定有某種心理疾病」等診斷式敘述；概念解釋以教育用途為主。

## 如何新增一篇心理學概念
1. 只需在 `assets/data.js` 的 `window.PSYCHOLOGY_TOPICS` 陣列新增一個物件。
2. 欄位必填：`id`（唯一、英文小寫加連字號）、`title`、`english`、`category`（`社會心理` / `認知心理` / `學習與記憶`）、`summary`、`detail`、`example`、`takeaway`、`question`、`options`（剛好四個字串）、`answer`（0~3 的索引）、`explanation`。
3. 不需複製一份新 HTML，概念清單、詳情與小測驗應自動讀取新增資料。
4. 如果新增新類別，也要同步更新 `assets/app.js` 的分類選單或改成自動生成，避免新內容無法篩選。
5. 每篇解釋與例子要能被一般學生理解；不要只貼定義或長篇 AI 套話。

## 互動規則
- 搜尋需能匹配中文標題、英文名與描述；沒有結果時顯示友善提示。
- 收藏需可切換、刷新後仍存在；不應上傳任何資料。
- 測驗須能選答案、顯示答對與否和解析、進入下一題；每次重新開始時重置分數。
- 修改內容或版面時，不能使既有頁面、導覽連結和測驗失效。

## 修改與驗收流程（AI 需要遵守）
1. 修改前先閱讀 `AGENTS.md`、`assets/data.js` 與相關頁面。
2. 優先用現有檔案和架構完成需求，不隨意新增框架或後端服務。
3. 新增頁面時，在所有頁面的導覽列加入連結，並延用頁首／頁尾視覺與 CSS。
4. 修改完成後檢查：首頁可開啟、概念卡片能連到詳情、搜尋篩選正常、收藏持久化、小測驗能作答、手機版無橫向溢出。
5. 用 `python -m http.server 8000` 在專案根目錄測試，瀏覽 `http://localhost:8000`。若無法啟動瀏覽器，至少檢查檔案路徑及 JavaScript 語法。
6. 說明做了哪些修改、如何驗證，避免聲稱未實際執行的測試已通過。
